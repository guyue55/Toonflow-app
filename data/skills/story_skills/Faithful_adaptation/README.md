# 忠实原著 · 导演叙事手法技能包

## 简介

本技能包为 **忠实原著 · 漫剧影视化改编** 提供一套完整的导演叙事手法参考，重点解决 AI 编导在改编过程中容易出现的"脱离原著、擅自加戏、套路化魔改、粗暴删减人物"等问题。涵盖从宏观叙事规划到微观分镜执行的全流程保真与视听化转化指导。适用于任何题材的小说改编。

## 核心理念

- **忠实为纲** — 严格依循小说原著主线、人物性格与核心设定，不做颠覆性魔改
- **去套路化** — 严禁强加不属于原著的低俗打脸、系统外挂或恶俗冲突
- **只浓缩不捏造** — 删减冗长环境铺垫与次要过场，严禁凭空捏造未发生的情节与结局
- **展示大于告诉** — 将原著大段心理活动与世界观叙述，转化为具体可拍的动作交互、微表情与镜头语言

## 技能文件说明

### 1. 叙事规划手法 (`director_planning_narrative.md`)

导演在 **叙事规划与骨架构建阶段** 使用的技法参考，定义忠实原著在主题立意、主线保真边界、人物关系保留、删减原则与世界观呈现上的整体规划方法。

| 章节 | 内容概要 |
|---|---|
| 主题立意与保真内核 | 尊重原著灵魂、拒绝同质化套路、保留人物原汁原味的动机 |
| 叙事结构与删改红线 | 主线事件 100% 对应、严禁篡改胜负结局、群像与配角保护 |
| 原著高光与名场面保护 | 原著关键战役/对话/高燃时刻必须保留，作为单集核心锚点 |
| 世界观与背景转化 | 拒绝大段旁白灌输，通过角色动作与局部交互自然带出 |
| 节奏把控与分集闭环 | 顺应原著自然节奏，拒绝生硬的人工狗血卡点 |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)

导演在 **分镜表制作与逐集编写阶段** 使用的技法参考，定义在分镜表中如何精准还原小说名场面、提炼原版台词、景别运镜与视听语言转化。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 分镜表作为原著文字向视觉画面精准转译的核心工具 |
| 台词提炼原则 | 保留原著高光金句，删减流水账废话，每句台词承载性格与冲突 |
| 景别与动作设计 | 将小说心理描写转化为具体的眼神、微动作、物理交互 |
| 运镜与镜头节奏 | 贴合原著情绪氛围的运镜轨迹，保障 AI 生成画面连贯性 |
| 细节与道具呈现 | 严格还原原著描写的标志性法宝/道具、服饰、环境特征 |

## 使用方式

本技能包在项目配置中选择后自动生效，指导 Toonflow 编导 AI：

1. **故事骨架与改编策略** — 严格锁定原著事件边界，拒绝无端脑补与魔改
2. **分镜与单集剧本** — 精准转译原著对白与画面，实现工业化高质量漫剧交付
